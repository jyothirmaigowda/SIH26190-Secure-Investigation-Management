# Module ownership

| Member | Ownership |
| --- | --- |
| Member 1 | Authentication, Main UI, Integration |
| Member 2 | Case Management |
| Member 3 | Documents and Evidence Security |
| Member 4 | Backend, Database, Authorization, Audit, and AI |

Developers should avoid modifying another member's module unless the team agrees first. Shared contracts, integration points, and cross-module changes must be discussed before implementation.
